## 🌱 Learning Goals
 
This project was created to practice and consolidate concepts learned during Front-End Technologies studies.
 
Main focus areas:
 
- Building responsive layouts with Bootstrap
- Working with CSS Variables and themes
- DOM manipulation using JavaScript
- jQuery event handling
- Bootstrap components integration
- Version control using Git and GitHub
 
During development, Git branches, commits and merges were used to simulate a real-world development workflow.
